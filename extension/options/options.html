NoteMate for chess.com

chess.com
NoteMate

Fair play. chess.com does not allow outside help during a game. This extension does nothing while a game is in progress in any chess.com tab: no button, no game lists, no requests. It opens only games that have finished and that chess.com's public API lists in your archive. It never reads positions from the page or touches the board. It stores only your public username, never a password or cookie.
